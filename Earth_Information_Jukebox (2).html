How does it work?
This project demonstrates Data Sonification — converting information into sound. Different sound features, such as pitch, rhythm and tone, can represent environmental conditions.

Science note: This version uses sample demonstration values, not live NASA measurements. In a full NASA-data version, real environmental observations would control the sounds.
